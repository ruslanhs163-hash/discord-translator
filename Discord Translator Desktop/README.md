# Discord Translator Easy (Desktop)

Небольшой установщик автоперевода для Discord Desktop на Windows. Не требует Node.js, npm, Python, Visual Studio или прав администратора: необходимые файлы уже входят в папку.

## Установка

1. Закройте Discord.
2. Откройте папку `Discord Translator Desktop`.
3. Запустите `Discord Translator Easy.bat`.
4. Нажмите `1` и дождитесь сообщения `Готово`.
5. Запустите Discord.

Если Windows покажет SmartScreen для скачанной папки, это предупреждение о неподписанном скрипте, а не запрос пароля или ключа. Не запускайте файлы, если источник папки вам неизвестен.

## Удаление

Запустите `Discord Translator Easy.bat`, нажмите `2`. Удалятор восстанавливает оригинальные `core.asar` и `index.js` из резервных копий, созданных при установке.

## Как это работает

Новая сборка не требует Node.js, npm, Python, архиваторов или прав администратора. `.bat` запускает Windows PowerShell; встроенный в Windows .NET-код меняет `mainScreenPreload.js` внутри `core.asar`, проверяет полученный архив и сохраняет исходные `core.asar` и `index.js` рядом как резервные копии.

Переводчик использует тот же `discordTranslatorVencord.js`, что и исходная версия: кнопка появляется в основном окне Discord, сообщения переводятся через Google Translate. Запрос перевода проходит через IPC-обработчик в `index.js`, а оригинальный текст и интерфейс перевода сохраняются по прежней логике.

Текст отправляемых и получаемых сообщений передаётся внешнему сервису Google Translate.

## Важно

- Только Windows x64 и Discord Desktop.
- Discord должен быть запущен хотя бы один раз, чтобы его core-модуль появился на диске.
- Обновление Discord может заменить пропатченный `core.asar`. После крупного обновления запустите установку повторно.
- Удаление восстанавливает резервную копию, сделанную при первой установке этой версии. Не удаляйте `.easy-backup.asar` вручную, пока используете переводчик.
- Сборка не включает отдельный runtime и не запускает скачанные исполняемые файлы.
